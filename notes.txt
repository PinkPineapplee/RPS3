

## ⚠️ What You Can Improve

### 1️⃣ **Scope and variable reference issues**

In your `updateScoreBoard()` and `scoreCondition()` functions, you’re using variables that aren’t in scope.

Example:

```js
if(gameStart === true && playerOneWins === true){
```

Here, `gameStart`, `playerOneWins`, and `playerTwoWins` are *not defined* in this scope.

✅ **Fix:**
Use references from your objects:

```js
if (control.gameStart && playerOneWins) {
  scoreBoard.playerOneScore[1] += 1;
  alert(`${scoreBoard.playerOneScore[0]} scored 1 point`);
}
```

and make sure you return the winner info properly from `scoreCondition()` so you can use it in `updateScoreBoard()`.

### 2️⃣ **Your `scoreCondition()` logic has a small bug**

Inside `scoreCondition()` you do:

```js
const b = gameBoard.boardArray;

for (let combo of wins) {
  const [a, b, c] = combo;  // ⚠️ 'b' here overwrites the earlier variable b
```

✅ **Fix:**
Rename that inner `b` variable:

```js
const board = gameBoard.boardArray;

for (let combo of wins) {
  const [a, i, j] = combo;
  if (board[a] && board[a] === board[i] && board[a] === board[j]) {
    return board[a] === "X" ? "X" : "O";
  }
}
return null;
```

Now you can easily check:

```js
const winner = scoreCondition();
if (winner === "X") scoreBoard.playerOneScore[1] += 1;
else if (winner === "O") scoreBoard.playerTwoScore[1] += 1;
```

### 3️⃣ **Error Handling ideas (you asked this!)**

Here’s where you can improve robustness:

**🔸 1. Prevent double-starts**
In `playGame()`, check if `this.gameStart` is already true:

```js
if (this.gameStart) {

```

**🔸 2. Protect against missing DOM elements**
Before using `document.querySelector`, check:

```js
const button = document.querySelector(".button");
if (!button) {
  console.error("Start button not found!");
  return;
}
```

**🔸 3. Validate player names**

```js
const playerOneName = prompt("Enter name for X") || "Player X";
const playerTwoName = prompt("Enter name for O") || "Player O";
```

So your game never crashes if someone cancels the prompt.

### 5️⃣ **Game over timing**

Currently, `this.gameOver()` runs every click — even before checking who won.
Ideally, check for a winner **inside** `play()` before calling `gameOver()`:

```js
const winner = scoreCondition();
if (winner) {
  alert(`${winner} wins!`);
  updateScoreBoard();
  this.gameOver();
  return;
}
```
